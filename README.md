## Run it locally, step by step

1. **Install [Node.js](https://nodejs.org) 20** or newer.

2. **Get the code:**

   ```sh
   git clone https://github.com/Gitguy268/vinylplayerforspotifyold2.git
   cd vinylplayerforspotifyold2
   ```

3. **Install the dependencies:**

   ```sh
   npm install
   ```

4. **Add your own Spotify app credentials** as environment variables, then start it:

   ```sh
   node server.js
   ```
